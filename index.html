What it is

Peering Manager is an open-source BGP session management tool, written in Python on Django.

Built for network engineers, by network engineers. The code, the issues and the roadmap are public under Apache-2.0. Read it, file a bug, or send a patch.

What it does

Four jobs, done once, for every peer you add.

Source of truth

Internet exchanges, peer ASNs, sessions, routing policies and route servers live in one database.

One place to change, instead of a spreadsheet

Configuration

Jinja2 templates render the configuration each router takes. NAPALM pushes it and shows you the difference first.

Templates published for Junos, IOS, IOS XR, EOS, SR OS and VyOS

PeeringDB and IRR

Peer contacts, exchange presence and prefix limits come from PeeringDB. Prefix lists come from the IRR.

Both stay current without you touching them

REST API

Every action in the web interface has an endpoint behind it.

Your own automation can do the same work
